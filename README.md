# FMCG Demand Forecasting & Inventory Analytics

## Project Overview

This project analyzes over 3 million FMCG retail sales records across 54 stores and 33 product families. The objective was to identify sales trends, evaluate promotional impact, analyze store performance, and forecast future demand using Meta Prophet.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Streamlit
* Meta Prophet

## Key Features

* Product Family Sales Analysis
* City Revenue Analysis
* Store Performance & Stockout Risk Analysis
* Promotion Impact Analysis
* Monthly Sales Trend Analysis
* Demand Forecasting using Meta Prophet
* Interactive Streamlit Dashboard

## Key Insights

* Grocery I generated the highest sales among all product families.
* Quito recorded the highest city-level revenue.
* Store 44 was the best-performing store.
* Promotional products achieved approximately 7x higher average sales.
* Sales showed a strong upward trend between 2013 and 2017.
* December demonstrated the strongest seasonal demand pattern.

## Forecasting

A Meta Prophet model was trained on daily sales data to forecast future FMCG demand. The model successfully captured:

* Long-term growth trends
* Weekly seasonality
* Yearly seasonality
* Future demand projections

## Dashboard

The Streamlit dashboard provides business stakeholders with sales analytics, forecasting insights, and inventory planning support.
